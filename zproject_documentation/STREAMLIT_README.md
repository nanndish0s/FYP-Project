# Voice-Based XAI for AI Recruitment - Streamlit App

## 🚀 Quick Start

Run the web application:
```bash
streamlit run app.py
```

The app will automatically open in your browser at `http://localhost:8501`

## 📱 Features

- **Candidate Selection**: Choose from 23 analyzed candidates
- **Transcript Display**: View interview transcripts
- **C3 Predictions**: Interactive gauge charts for Curiosity, Critical Thinking, Creativity
- **SHAP Explanations**: See which features influenced predictions
- **Prosody Analysis**: Voice characteristics breakdown
- **Recruitment Recommendation**: Hire/no-hire decision with reasoning
- **Visualizations**: Embedded charts and plots

## 🎬 Demo Instructions

1. **Select a Candidate**: Use the dropdown in the sidebar
2. **Review Transcript**: Read the interview text
3. **See Predictions**: Check the C3 scores with visual gauges
4. **Understand Why**: Explore SHAP explanations in tabs
5. **View Prosody**: See voice characteristics analysis
6. **Get Recommendation**: Final hiring decision

## 💡 Tips

- Try different candidates to see varying predictions
- Click on SHAP tabs to see detailed explanations
- Expand the transcript viewer for full text
- Compare predicted vs actual scores

## 🛑 To Stop

Press `Ctrl+C` in the terminal running Streamlit
